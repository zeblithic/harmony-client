One engine. Many feeds. Vines first.
Underneath everything is one content-addressed store — every video, image, and post is just a CID. A feed is a lens over that store, filtered by media type. Swap the lens and the same surface becomes a different "app": 6-second loops → Vines · images → a gallery · short text → a microblog. The codebase already ships Vines for real (Following / Discover, All / Unviewed, reshare-with-attribution, reactions, an immersive player) — this restyles that faithfully and shows where the one-engine idea goes next. We launch with Vines because nothing else fills that gap anymore; the other two already exist elsewhere.
The thesis · one store, swappable lenses
🎞VinesLAUNCH
Lens = video/*, ≤6s, loops. Chronological. The format that died with Vine in 2017 — no one else offers it.
🖼GalleryLATER
Lens = image/*. Grid layout. Same follows, same reshare, same store — an Instagram-shape.
✍PostsLATER
Lens = text, ≤280. Threaded. Same engine, a Twitter-shape.
