**Goal:** close the five bounded-time / ordering defects in ZEB-853 (the last direct T-\* ticket of the ZEB-831 wall-clock threat model), each a peer-supplied or unit-confused stamp driving an ordering / freeze / admission decision.

Mirror the patterns the rest of the ZEB-831 series already established: control-tier forward-skew reject via `clock_trust` (C2), local-receipt ordering instead of a peer wall stamp (D5), full-tuple deterministic sort (E9), honest removal of inert dead code (D6), and a ZEB-700-style pre-auth Tier-1 connection shield (B7).

**Tech Stack:** Rust (`src-tauri/`, cargo + nextest), TypeScript/Svelte frontend (`src/`, vitest).

```ts
export function speakerQueue(roster: RosterMember[]): RosterMember[] {
  const cmp = (a: string, b: string) => (a < b ? -1 : a > b ? 1 : 0);
  const key = (m: RosterMember) => m.handFirstObservedMs ?? m.handRaisedAt!;
  return roster
    .filter((m) => m.handRaisedAt !== null)
    .sort((a, b) => key(a) - key(b) || cmp(a.ownerHex, b.ownerHex) || cmp(a.deviceHex, b.deviceHex));
}
```
