# ZEB-950 — moderator/member invites — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let any community member with power ≥ the community's `invite` threshold (default 0 = every member) generate a working community invite, instead of hardcoding "inviter must be `admin_addr`" at the mint.

**Architecture:** The receive/consensus side already permits this — ZEB-911's witness model puts admission authority on the *finalizing witness's* power, the token is device-signed and verified against the inviter's enrolled keys (inviter-agnostic), and the frontend already gates the invite control on `myPower >= thresholds.invite`. The only active block is one client-side mint guard. So the change is: (1) replace that guard with a power-threshold check, (2) prove end-to-end that a moderator-originated invite redeems with the admin absent, (3) optionally rename the mislabeled `admin_identity_pub` → `inviter_identity_pub` (wire key unchanged), (4) verify the frontend reachability + coverage.

**Tech Stack:** Rust (Tauri backend, `src-tauri/`), `cargo nextest`; Svelte 5 + TypeScript frontend, `vitest`/`tsc`.

**Spec:** `docs/superpowers/specs/2026-08-16-zeb950-moderator-member-invites-design.md`

```rust
/// ZEB-950: an invite may be generated by any member whose power meets the
/// community's `invite` threshold (default 0 = every member). This replaces
/// the v1 admin-identity lock. NOTE: this is a client-side/advisory gate —
/// the consensus boundary is the witness countersign power check in
/// `verify_event` (ZEB-911). A demoted member who bypasses this still cannot
/// get an invite finalized without a sufficiently-powered witness.
fn invite_generation_power_guard(self_power: u8, invite_threshold: u8) -> Result<(), String> {
    if self_power < invite_threshold {
        return Err(format!(
            "insufficient power to generate an invite: have {self_power}, need {invite_threshold}"
        ));
    }
    Ok(())
}
```
