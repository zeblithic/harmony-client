# Harmony v0.2.7

**A polish-and-usability release.** Where v0.2.6 hardened the layers underneath, v0.2.7 fixes the things you touch every day: invite links you can actually paste into a message, real names instead of hex across the app, and clocks and dates that follow your preferences. Roughly 27 changes since v0.2.6.

> ⚠️ **Alpha software — and self-sovereign by design.** Harmony is peer-to-peer: **your identity lives only on your own devices.** If you haven't already, open **Settings → Account** and export your recovery kit — there is no server-side account recovery. Expect rough edges, and please report what you find.

---

## ✨ Highlights

- **Invite links that fit in a message.** Community invites are now compressed and no longer embed a snapshot of the member roster, shrinking them from unwieldy blobs to links you can paste into any messenger. The member list syncs in normally right after you join — you may briefly see the community filling in, which is expected.
- **Anyone with the power can invite.** Generating invites is no longer an admin-only privilege: any member above the community's invite threshold can mint them, moderator-minted invites are now correctly accepted by every member's local rules, and the redeem flow's copy stopped assuming an "admin" on the other end — including a clear explanation when the LAN fallback is offered.
- **Real names, everywhere.** Friends, DMs, file sharing, calls and voice, moderation dialogs, joins, invites, mail, and thread/avatar labels now all resolve names the same way — nickname first, then the peer's published profile name, with the raw address only as a last resort. Names that arrive mid-call update in place, and whitespace-only names are rejected at the door. If you still see raw hex somewhere, that's now a bug worth reporting.
- **Your clock, your way.** Pick 12/24-hour time and date order in Settings and it now applies across the app's date surfaces; the chat log finally shows message *dates* (so cross-day threads stop reading as "just now"), and Mail groups messages by your actual calendar day.

## 🔧 Under the hood

- **Storage admission hardening.** The content store now separately answers "may this node relay these bytes" and "may this node publish them" for encrypted-durable content — defense-in-depth from the harmony core update, so a future change to one rule can't silently widen the other.
- **Router-mode refinements.** In the (still flag-gated) bounded-degree topology mode: boot no longer over-dials before the admission oracle knows the address book, and a peer that is the sole bridge to a stranded island is no longer parked by ring-neighbor admission.
- **Quieter logs on IPv4-only networks.** iroh's IPv6 address-discovery probes no longer spam warnings when there is no IPv6 route.

---

## 🧪 What to test

- **Invites:** as a non-admin member with invite power, generate an invite, send the link through a real messenger, and redeem it on another machine — confirm the join completes and the member list fills in shortly after.
- **Names:** sweep the surfaces you use — friends, DMs, calls, moderation dialogs, mail — and report any place that still shows a raw hex identifier.
- **Time & date:** flip the 24-hour clock and date-order preferences in Settings, then check chat-log dates, mail grouping, and any standalone date surfaces you can find.
- **Everyday paths:** DMs, voice, community join — confirm nothing regressed.
