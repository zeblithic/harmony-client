# Harmony v0.2.8

**A polish-and-usability release — plus a critical join fix.** v0.2.7 was cut as a release candidate but never published: smoke-testing it surfaced a long-latent bug that could permanently wedge cross-machine community joins. v0.2.8 ships that fix, a reworked channel navigation, and everything v0.2.7 contained. Roughly 30 changes since v0.2.6.

> ⚠️ **Alpha software — and self-sovereign by design.** Harmony is peer-to-peer: **your identity lives only on your own devices.** If you haven't already, open **Settings → Account** and export your recovery kit — there is no server-side account recovery. Expect rough edges, and please report what you find.

---

## 🚨 Fixed: joins could permanently wedge on ordinary clock skew

If the machine approving your join had its clock even a few hundred milliseconds **behind** yours — a completely normal NTP disagreement — the join could silently wedge forever: you'd see the community and read the admin's messages, but you never appeared on the member roster (not even your own copy of it), and nothing you posted reached anyone. Whether a first join worked was effectively a coin flip per direction, and the app's own repair passes couldn't fix it. The bug had been latent for several releases.

v0.2.8 stamps the join approval with proper clock discipline so honest joins are immune to skew, and teaches every self-heal path to recognize and replace a bad approval. **Communities that are already wedged repair themselves** — once the member who approved your join is running v0.2.8, the fix propagates to every member automatically, no manual steps. Messages you "lost" into a wedged community were never actually discarded and will backfill as it heals.

## ✨ Highlights

- **Channel navigation moved next to Members.** Each community's channel list now lives in the right-hand panel, toggled with the new **#** button beside the Members (👥) and Settings (⚙️) buttons: **proposals** pinned on top, channels beneath, and the permission-gated **＋ add channel** row at the bottom — so it can never shift the sidebar layout again. The left sidebar is now a clean, flat list of communities (no more expand/collapse), and on narrow windows — where the sidebar shrinks to icons — your channels stay reachable in the panel. **Notes** moved down to sit as a button alongside Messages / Vines / Files.
- **Invite links that fit in a message.** Community invites are now compressed and no longer embed a snapshot of the member roster, shrinking them from unwieldy blobs to links you can paste into any messenger. The member list syncs in normally right after you join — you may briefly see the community filling in, which is expected.
- **Anyone with the power can invite.** Generating invites is no longer an admin-only privilege: any member above the community's invite threshold can mint them, moderator-minted invites are now correctly accepted by every member's local rules, and the redeem flow's copy stopped assuming an "admin" on the other end — including a clear explanation when the LAN fallback is offered.
- **Real names, everywhere.** Friends, DMs, file sharing, calls and voice, moderation dialogs, joins, invites, mail, and thread/avatar labels now all resolve names the same way — nickname first, then the peer's published profile name, with the raw address only as a last resort. Names that arrive mid-call update in place, and whitespace-only names are rejected at the door. If you still see raw hex somewhere, that's now a bug worth reporting.
- **Your clock, your way.** Pick 12/24-hour time and date order in Settings and it now applies across the app's date surfaces; the chat log finally shows message *dates* (so cross-day threads stop reading as "just now"), and Mail groups messages by your actual calendar day.

## 🔧 Under the hood

- **Channel permissions follow your community's rules.** The add/rename/delete channel controls (and their dialogs) now gate on the community's own customized moderation threshold — the value the protocol actually enforces — instead of the global default.
- **Storage admission hardening.** The content store now separately answers "may this node relay these bytes" and "may this node publish them" for encrypted-durable content — defense-in-depth from the harmony core update, so a future change to one rule can't silently widen the other.
- **Router-mode refinements.** In the (still flag-gated) bounded-degree topology mode: boot no longer over-dials before the admission oracle knows the address book, and a peer that is the sole bridge to a stranded island is no longer parked by ring-neighbor admission.
- **Quieter logs on IPv4-only networks.** iroh's IPv6 address-discovery probes no longer spam warnings when there is no IPv6 route.

## 🧪 What to test

- **Joins, both directions:** create a community on machine A, join from machine B — then the reverse. Confirm both sides end up on the member roster and messages flow both ways. If you have a community that wedged under an earlier build, just run v0.2.8 on both machines and watch it repair itself.
- **Channel panel:** toggle **#** / 👥, switch channels from the panel, create/rename/delete a channel (if you have the power), open Proposals from the top row, and shrink the window — channels should stay reachable.
- **Invites:** as a non-admin member with invite power, generate an invite, send the link through a real messenger, and redeem it on another machine — confirm the join completes and the member list fills in shortly after.
- **Names:** sweep the surfaces you use — friends, DMs, calls, moderation dialogs, mail — and report any place that still shows a raw hex identifier.
- **Time & date:** flip the 24-hour clock and date-order preferences in Settings, then check chat-log dates, mail grouping, and any standalone date surfaces you can find.
- **Everyday paths:** DMs, voice, community join — confirm nothing regressed.

## ⚠️ Known issues

- **macOS: one Terminal command is required on first install.** Harmony deliberately ships without an Apple Developer certificate (a recurring paid program), so Gatekeeper blocks the first launch and — despite what the dialog implies — offers **no working way to approve the app through the normal flow** (no functional right-click → Open, no "Open Anyway"). After dragging Harmony to Applications, run:

  ```bash
  xattr -dr com.apple.quarantine /Applications/Harmony.app
  ```

  then launch normally. This is one-time per install and permanent policy, not a bug we can fix in a later build. Full walkthrough: [docs/install-macos.md](../install-macos.md).
