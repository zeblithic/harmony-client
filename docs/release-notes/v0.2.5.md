# Harmony v0.2.5

**The first published Harmony build since v0.1.2 (June 27).** The `0.2.0`–`0.2.4` tags were internal alpha checkpoints that were never published, so this release folds in **everything from the last six weeks — roughly 290 changes** touching nearly every part of the app. It's a big one. This page leads with a readable summary; the complete commit-level changelog is collapsed at the bottom.

> ⚠️ **Alpha software — and self-sovereign by design.** Harmony is peer-to-peer: **your identity lives only on your own devices.** Open **Settings → Account** and export your recovery kit before you do anything else — there is no server-side account recovery. Expect rough edges, and please report what you find.

---

## ✨ Highlights

- **A complete visual redesign ("Commons").** A brand-new design system with light + dark themes that can follow your OS setting, self-hosted fonts, and a restyled shell top to bottom — navigation, onboarding, governance, files, calls, and every panel.
- **Direct messages grew up.** Tiered invite consent (friends auto-accept, strangers ask first), unread badges, opt-in per-DM read receipts, delivery that survives restarts, and history that survives a reconnect.
- **Voice calls you can actually drive.** Live microphone/speaker pickers with hot-switching, a missed-call + call-history surface, and Town Hall assembly calls with a raise-hand speaker queue.
- **Real multi-device.** Enroll extra devices, see each device's last-seen, give them petnames, and revoke a lost one — with a quorum-signed key rotation so a revoked device is genuinely cut off. "Replace this device" re-pairs in a single flow.
- **Cross-network connections that hold.** Upgraded to **iroh 1.0** with stable relays, a per-peer reconnect supervisor, direct NAT hole-punching proven across genuinely separate networks, and a Network Health panel that reports the truth about each peer.
- **Private file sharing.** Per-recipient encrypted sharing with a "Shared with me" browser, streaming encryption for large files, and community "storage buddies" that pledge to keep your content available.
- **A short-form "Vines" feed.** Scroll-snap autoplay, a follow-graph Discover, signed posts, reactions, and creator delete.
- **Governance for communities.** Per-community power thresholds, conviction voting with auto-executed outcomes, a generated Charter, community fork + lineage, and time-locked, veto-able admin recovery.

## 🎨 Interface & experience

- A full "Commons" redesign: semantic design tokens, re-valued light **and** dark palettes, self-hosted fonts, and a **follow-system theme** with a per-identity override.
- Restyled everywhere — navigation shell, onboarding, governance surfaces, the generated Charter view, fork & lineage, Friends, Network, Bridging, Mail, Pending Joins, and the call/voice views.
- A rebuilt **onboarding wizard** with an honest recovery-kit step and a clearer Devices panel.
- Accessibility passes throughout: focus-trapped dialogs, `alertdialog` roles, on-accent contrast fixes, and keyboard-reachable controls.

## 💬 Messaging, channels & mentions

- **@-mentions** with compose autocomplete, resolved rendering, contenteditable chips, and hex-discoverable fallback — plus **mention notifications** (nav badge + focus-aware toast/OS notification).
- **Channels are first-class**: they appear as navigation nodes, carry **per-channel unread counts**, and have a keyboard-accessible moderation menu.
- Duplicate channel names are rejected; messages can load newest-first.
- Faster, lighter reconnects: channel history catches up by exchanging only the differences (range-based set reconciliation) instead of replaying whole logs, and survives restarts.

## ✉️ Direct messages

- **Tiered consent** on incoming DM invites — friends auto-accept, strangers prompt you to accept or decline.
- **Unread badges** per thread and **opt-in, per-DM read receipts** (off by default).
- Durable delivery: the DM outbox persists across restarts and flushes on quit, closing message-loss windows.
- Full message-history pagination, and DM identity is **certificate-anchored** with revocation cutoffs so a revoked device can't keep speaking as you.

## 🔊 Voice, calls & Town Hall

- **Live device pickers** for microphone and speaker with hot-switching mid-call, plus a shared media-reconnect driver.
- **Missed-call and call-history** surface, delivered as caller-authored call events.
- **Town Hall** assembly calls: a speaker spotlight, raise-hand beacon, invite-to-speak, and a quorum-aware motion card.

## 🏛️ Communities, governance & voting

- **Per-community power thresholds** for invite / kick / set-power, with admin-affecting changes always requiring admin power.
- **Conviction voting** with outcomes that auto-execute (e.g. power changes routed through an admin proposal), plus vote backfill and local persistence so results survive a restart, and an epoch-encrypted voting channel.
- **Community fork + lineage**: a mandatory "why" on every fork and a 2-D genealogy graph.
- Community presence enrichment (member counts, sorting, cross-community indicators, invisible mode) and a "left communities" management surface with typed-confirm delete.

## 🎬 Vines (short-form feed)

- A scroll-snap **autoplay feed** with restart-proof hydration and an honest publish gate.
- **Discover** built from your transitive follow graph (signed follow lists, 2°/3° reach, tunable).
- Signed post + reaction records, reactions that rehydrate on boot, creator **delete** (signed tombstone), and follow-only relay fan-out across nodes.

## 📁 Files & storage

- **Per-recipient encrypted file sharing** — create → share → read — with a "Shared with me" browse-and-download surface.
- **Streaming (chunked, fully-authenticated) encryption** for large files.
- **Storage buddies**: signed pledge/backup/hosting records, a budget-enforced auto-pin engine, observed replica counts, and a contribution meter.
- Owner-driven revoke that prunes a grantee's access.

## 🔑 Identity, devices & recovery

- **Multi-device trust replication**: enrollments, vouching, revocations, and liveness sync across your own devices.
- **Device revocation** with a quorum-signed fleet key-rotation, "Replace this device" re-pairing, per-device last-seen, and fleet-synced petnames.
- **Owner recovery phrase** deliberate-reveal export, and a two-tier identity reset (clean-slate erase) with honest recovery copy.
- **Admin recovery** for communities: designated recoverers, time-locked and veto-able.
- Self-serve escape hatch for a terminal boot failure (reset/restore) instead of a dead end.

## 🌐 Connectivity & networking

- Upgraded to **iroh 1.0** (stable relays by default) with a **per-peer reconnect supervisor** and liveness state machine replacing dial-once.
- Direct-path **NAT traversal** validated across real separate networks (a dedicated cross-WAN test node), plus rendezvous-beacon bootstrap so a cold node can reach a community with zero prior sessions.
- A **Network Health** panel that reports real per-peer connection mode, round-trip time, display names, and honest traffic-staleness.
- Killed the macOS first-bind stall that made cold starts hang.

## 🎟️ Invites & discovery

- **Invite preview**: a pure-local decode/verify card before you commit to redeeming.
- **Single-use invite claims** enforced end-to-end, structured (typed) redeem error codes, and retry that reuses a minted redemption so a failed delivery is still redeemable.
- **Identity discoverability** is on by default (with an onboarding note and a runtime toggle that persists even on a stopped node), and reachability records are bounded to fit discovery limits — with a signal when they can't.
- Cross-network invite redemption now tells you honestly when you've joined as **pending** (awaiting an offline admin's approval) instead of a flat "Joined ✓".

## 🛡️ Security, privacy & robustness

Much of this release is invisible but load-bearing — a broad hardening pass so the app behaves under clock skew, malicious peers, and flaky networks:

- A **bounded-time trust** epic: peer-supplied timestamps are forward-skew-bounded and validated at every boundary (governance, mint, profile cards, discovery, voting, storage receipts), with honest logical-clock (HLC) causal adoption.
- **Sybil/flood defenses**: node-wide open-join admission ceilings, an in-flight handshake gate, and per-source inbound-tunnel rate + concurrency limits.
- **Revocation everywhere**: feed authority, DM signing, and storage records all carry revocation-aware verification so a removed device loses access promptly.
- Hardened decoders, fail-fast validation on hot paths, and durable panic capture for a masked native crash.

## 🧰 Platform, install & the headless agent

- **macOS**: the app bundle is ad-hoc sealed and the install docs explain the Gatekeeper "damaged" prompt (see Known issues).
- **Auto-update** is cryptographically signed across all four platforms (macOS Intel/Apple-Silicon, Windows, Linux).
- The **headless agent surface** (`serve` / `api` / `watch`) gained file-sharing, read-receipt, and voting verbs and clearer, honest responses — the foundation for automated multi-node testing.

## ⚠️ Known issues

- **Redeeming an invite while the admin is offline:** you'll join an invite-only community as **pending**, and it unlocks once the admin comes back online and approves — usually seconds, up to a few minutes on first contact. The redeem dialog now says so explicitly. (Convergence-latency follow-up tracked for a later build.)
- **macOS says the app is "damaged":** this build is ad-hoc sealed but not notarized. Right-click the app → **Open**, or run `xattr -dr com.apple.quarantine /Applications/Harmony.app`. It's a distribution quirk, not a corrupted download.
- **Updating from v0.1.2:** because the 0.2.x builds were never published, existing 0.1.2 installs update straight to 0.2.5.
- Cold-start peer discovery and cross-network connections can take a few seconds to settle.

## 🧪 What to test (and please report)

- **Onboarding + recovery**: create an identity, export the recovery kit, then try a clean restore.
- **Invites across networks**: create an invite-only community, redeem from another machine on a different network — including while the host is offline.
- **DMs**: friend vs. stranger invite consent, unread badges, and toggling read receipts.
- **Voice**: place a call, switch mic/speaker mid-call, check call history; try a Town Hall.
- **Multi-device**: enroll a second device, set petnames, then revoke one and confirm it's cut off.
- **Files**: share an encrypted file (small and large) and download it as the recipient.
- **Communities**: adjust power thresholds, run a vote to completion, fork a community.

Feedback and bug reports are hugely welcome — thank you for testing an early build. 💛
